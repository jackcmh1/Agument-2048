# 증강 2048 · MVP v0.1

React + TypeScript + Vite로 만든 4×4 증강 2048입니다. 서버나 계정 없이 동작합니다.

## 실행

Node.js 24 권장.

```sh
npm ci
npm run dev
```

브라우저에서 개발 서버가 안내하는 `/Agument-2048/` 경로를 엽니다.

```sh
npm test
npm run build
npm run preview
```

PC는 방향키/WASD, 모바일은 보드 위 스와이프를 사용합니다. 화면의 방향 버튼도 사용할 수 있습니다. 진행 중인 런은 브라우저 localStorage에 자동 저장됩니다. 새 게임 시 초기화됩니다.

## 규칙과 구현 선택

- 32, 64, 128, 256, 512, 1024 최초 달성 시 중복 없는 증강 3개 중 하나를 선택합니다.
- 15종: A001~A015. 등급에 관계없이 동일 확률로 제시합니다.
- A004/A008 발동 이후 각각 다음 4/8회의 유효 이동을 모두 대기합니다.
- M02는 현재 이동의 합성 결과를 보호하며, 제거 기회는 누적됩니다. 작은 숫자, 행 우선 좌표 순으로 제거합니다.
- A006/B02는 획득 직후 충전되어 있으며 사용 후 15/12회의 유효 이동이 필요합니다. B02는 선택한 행과 바로 아래 행을 교환합니다.
- A009(타일 복제, 희귀)은 숫자 타일을 선택한 뒤 빈칸을 선택하면 같은 숫자를 복사합니다. 획득 직후 사용 가능하며 사용 후 60회의 유효 이동으로 충전됩니다. 선택 중 취소·대상 변경이 가능하고, 빈칸이 없으면 사용할 수 없습니다. 복제는 점수·일반 생성 횟수·이동 횟수를 소모하지 않습니다.
- 생성 취소는 일반 생성 카운터와 예고 숫자를 소비하지 않습니다. 시작 타일은 생성 카운터에서 제외합니다.
- 일반 이동이 불가능해도 충전된 유효 복구 능력이 있으면 플레이를 유지합니다.
- 첫 2048 달성 시 승리 화면을 표시합니다. 이어서 하기를 누르면 보드·점수·증강을 유지하고 4096 이상에 도전할 수 있으며, 승리 화면은 다시 표시하지 않습니다. 이어하기 상태도 자동 저장됩니다.
- 런 기록 내보내기는 시드, 게임 상태, 최근 효과 로그와 발동 횟수를 JSON으로 저장합니다. 외부 수집은 없습니다.

증강 등급은 `src/engine.ts`의 `rarities`(일반/common, 고급/uncommon, 희귀/rare)로 정의합니다. 카드의 `rarity`를 지정하면 드래프트, 보유 목록, 능력 버튼에 공통 색상과 등급명이 자동 적용됩니다. 기존 카드 등급은 유지하며 고급 등급은 추후 카드에 지정할 수 있습니다. 색상은 `src/style.css`의 등급별 CSS 변수에서 관리합니다.

게임 규칙은 `src/engine.ts`의 순수 상태 전이로 UI와 분리되어 있습니다. 카드 정의는 `cards`, 효과는 `applyAction`에 모여 있습니다. 새 카드 효과를 추가할 때 이동/합성 함수는 수정할 필요가 없습니다. `src/engine.test.ts`에서 핵심 규칙과 결정론을 검증합니다.

## GitHub Pages: Deploy from a branch

`.github/workflows/deploy.yml`은 main 푸시 시 설치 → 테스트 → 빌드 후 결과를 `gh-pages` 브랜치에 배포합니다. PR에서는 검증만 실행합니다. 첫 성공 배포 시 브랜치가 자동 생성됩니다.

1. 변경 사항을 GitHub의 main에 반영합니다.
2. Actions에서 `Validate and deploy Pages`가 성공했는지 확인합니다.
3. Settings → Pages → Source: **Deploy from a branch**.
4. Branch: **gh-pages**, Folder: **/ (root)** 선택 후 Save.
5. Pages 배포 완료 후 `https://jackcmh1.github.io/Agument-2048/`에 접속합니다.

저장소 정책에서 Actions의 브랜치 쓰기를 제한하면 Settings → Actions → General에서 워크플로 쓰기 권한을 허용해야 합니다. 저장소 이름을 바꾸면 `vite.config.ts`의 base도 수정합니다. 공개 사이트와 저장소 공개 여부는 GitHub 설정에 따릅니다.

A010(타일 교환, 고급)은 서로 다른 숫자 타일 두 개의 위치를 바꿉니다. 획득 직후 사용 가능하며 사용 후 40회의 유효 이동으로 충전됩니다. 빈칸 및 같은 숫자끼리 교환은 충전을 소모하지 않습니다. 선택한 첫 타일을 다시 누르면 선택이 해제됩니다.

## 반복 테스트 모드

`https://jackcmh1.github.io/Agument-2048/?test`에서 별도 테스트 게임을 사용할 수 있습니다. 첫 줄 왼쪽에 1024 두 개, 둘째 줄 왼쪽에 2와 4를 배치하고, 타일 복제(A009)·타일 교환(A010)·성장 촉진(A011)을 충전 완료 상태로 보유하고 작은 수의 법칙(A012)·쌍둥이 탄생(A013)도 보유합니다. 기존 목표 보상은 처리된 상태이므로 선택 팝업이 연속해서 나타나지 않습니다.

테스트 재시작(승리·패배 화면의 재시작 포함)은 항상 같은 시드와 초기 설정을 복원합니다. 새로고침은 테스트 진행을 이어갑니다. 일반 저장 키 `augmented2048-v1`과 테스트 저장 키 `augmented2048-test-v1`을 분리해 일반 게임 진행을 보존합니다. 초기 설정은 `src/gameSession.ts`에서 관리합니다.


신규 증강:
- A011 성장 촉진(고급 사용형): 2·4·8을 선택해 두 배로 키우며 사용 후 25회의 유효 이동으로 충전합니다. 합성이나 일반 생성으로 집계하지 않습니다.
- A012 작은 수의 법칙(일반 패시브): 일반 생성 숫자를 2로 고정합니다. G03의 매 5번째 4 생성은 우선 적용됩니다.
- A013 쌍둥이 탄생(고급 패시브): 매 16번째 일반 생성에서 실제 생성된 숫자를 빈칸에 하나 더 생성합니다. 추가 타일은 생성 횟수에 세지 않으며 빈칸이 없으면 생략합니다. G02의 위치 선택은 첫 타일에 적용되고 쌍둥이는 나머지 빈칸 중 무작위 위치에 생성됩니다. 생성 취소·타일 복제·성장 촉진은 주기를 진행시키지 않습니다.

- A014 기사의 여정(희귀 사용형): 나이트 거리(가로 2·세로 1칸 또는 가로 1·세로 2칸)의 동일 숫자 두 타일을 합칩니다. 첫 타일을 선택한 뒤 강조된 상대를 선택하면 두 번째 위치에 합성됩니다. 첫 타일 재선택은 선택 해제, 취소는 충전 소모 없이 동작합니다. 사용 후 40회의 유효 이동으로 충전합니다. 합성 점수와 2+2 합성의 A005 진행은 반영하지만 일반 생성·이동 횟수는 소모하지 않습니다. 준비된 합성 쌍이 있으면 막힌 보드에서도 사용할 수 있습니다.
- 테스트 모드 재시작 시 B06도 준비되며, 2행 1열과 3행 3열의 2 타일로 나이트 합성을 바로 확인할 수 있습니다. 첫 줄의 1024 두 개는 유지됩니다.

## 고정 증강 ID

증강 ID는 등급 및 유형과 독립적인 `A001`~`A014`입니다. 등급·이름·효과 변경 시 ID를 유지하며 신규 증강에는 다음 번호를 부여하고 삭제한 번호는 재사용하지 않습니다. 도감은 ID 순으로 표시합니다.

### A015 한 걸음 뒤로

희귀 사용형 증강으로 획득 즉시 2회 충전되고 최대 2회 저장합니다. 직전 유효 이동을 한 번에 하나씩 되돌려 연속 2회 사용하면 두 이동 전으로 돌아갑니다. 보드·점수·일반 생성·다음 숫자·난수 시드·다른 증강의 충전/패시브 진행을 복원합니다. 생성 위치 선택과 쌍둥이 생성도 해당 이동에 포함됩니다.

사용분은 유효한 이동 50회마다 한 회씩 순차 재충전하며 가득 차면 충전 진행을 중단합니다. 되돌리기 자신의 충전 수·충전 진행·누적 사용 통계는 되돌리지 않습니다. 다른 사용형 능력이 실제 완료되거나 증강을 획득하면 이전 이동 기록은 비웁니다. 일반 이동 중과 승리/패배 결과 화면에서 사용할 수 있고, 증강/생성 위치 선택 중에는 사용할 수 없습니다. 기록은 최대 두 개이며 저장 후 다시 접속해도 유지합니다.

테스트 모드 재시작 시 A015도 2회 충전 상태로 보유합니다. 한 번 이상 이동한 뒤 사용할 수 있습니다.

### A016 전면 성장

희귀 일회용 증강입니다. 획득 즉시 발동하지 않고 원하는 순간 사용할 수 있습니다. 보드의 모든 숫자를 두 배로 키운 다음 일반 생성을 1회 진행하며, 빈칸이 없으면 생성만 생략합니다. 두 배 성장은 합성이 아니므로 점수나 합성 패시브 진행을 추가하지 않습니다. 이동 횟수 및 충전 시간도 소모하지 않습니다.

후속 생성은 생성 예고·선택받은 탄생·고급 생산 라인·작은 수의 법칙·쌍둥이 탄생의 규칙을 따르며, 생성 완료 후 목표/승리/패배를 판정합니다. 사용 후 보유 목록에 소모됨으로 남고 다시 제시되지 않습니다. 기존 되돌리기 기록은 비우며 저장·새로고침·이후 이동 되돌리기로 일회용 사용이 복구되지 않습니다.

테스트 모드 재시작 시 A016도 미사용 상태로 보유합니다.
